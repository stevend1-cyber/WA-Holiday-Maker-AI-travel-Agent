Welcome to the WA Holiday Finder

This tool uses Claude AI to search the web for real-time holiday deals. You'll need a free Anthropic API key to get started.

How to get your API key:
1. Go to console.anthropic.com and sign up (free)
2. Click API Keys in the left sidebar
3. Click Create Key and give it a name
4. Copy the key (starts with sk-ant-) and paste it below
You'll need to add a small amount of credit to your account. Each search costs approximately $0.05–0.15 AUD.

Your key is saved in your browser only and is never stored on any server. You only need to enter it once per device.
